# “日系动漫”视频风格说明书

- 版本：1.0
- 适用：番剧感科普、成长与挑战故事、轻松生活技巧、校园与青春题材、积极向上的概念讲解类{{ORIENTATION}}解说
- 基准画幅：{{CANVAS}}，30fps

## 1. 风格定位

“日系动漫”借用 TV 动画的观看体验来讲解内容：晴空与积云的赛璐珞背景，一张砸下来的话数标题卡，集中线把视线收向关键词，漫画分格把步骤一格一格推进，最后用一页设定资料收束。观众不是在“看信息图”，而是在“追一集番”。

它与另外两套二次元向风格的分工：

- **二次元锐利拼贴**：暗底红黄、斜切与评级，适合强观点和排行，气质是“酷”。
- **视觉小说对话**：夜色与对话框，适合安静的故事与情绪，气质是“静”。
- **日系动漫**：晴空与赛璐珞、分格与集中线，适合成长、挑战和轻快科普，气质是“燃”与“亮”。

五个关键词：

- **明亮**：白天的晴空是默认舞台，整体色调轻、饱和、干净。
- **热血**：标题砸入、集中线收拢、拟声字落定，节奏有冲劲。
- **分格**：信息按漫画分格组织，一格只讲一件事。
- **赛璐珞**：平涂加硬边阴影，统一的墨线描边，不用柔和渐变。
- **原创**：只借用番剧的共同语汇，不借用任何具体作品的角色、Logo、标题字形与构图。

## 2. 适用与不适用

适合：

- 成长、挑战、学习路线、“从零到一”的故事型讲解。
- 轻松科普、生活技巧、校园与青春题材。
- 需要情绪起伏和“燃点”的观点表达（例如“这一步才是关键”）。

不适合直接套用：

- 严肃新闻、灾难、医疗与法律等需要克制语气的题材。
- 数据密集的评测与报表、精确的架构图。
- 夜晚、悬疑、压抑氛围的内容（可以改用视觉小说对话或赛博故障）。

这些题材若要使用本风格，应把数据收进设定资料卡里，每格只留一条结论，并降低集中线和拟声字的使用频率。

## 3. 叙事原则

每个镜头先写一句“这一集的台词”，再写布局：

> 这一拍的主角是什么？观众必须读到的是哪一个词？集中线指向哪里？读完后画面停在哪一格？

优先使用以下叙事动作：

1. **开播**：话数标题卡点明本段主题，像番剧每集开头的标题。
2. **冲突**：用分格对照摆出“以为是这样 / 其实是那样”。
3. **推进**：用分镜格一步步展开，每一格一个动作或一个因果。
4. **燃点**：集中线 + 拟声字把关键词砸出来，全片只给最重要的一两处。
5. **设定**：把本段要点整理成一页设定资料，作为可以回看的总结。
6. **下集预告**：结尾可以用“NEXT EPISODE”小标引出下一段，不是必须。

## 4. 画布与安全区

### 4.1 五层安全区

以 frontmatter 的 `safe_area` 为准；它由画幅推导为绝对像素。

| 区域 | 用途 |
|---|---|
| `structural` | 云、集中线外圈、分格外框、话数角标 |
| `main_content` | 分格、设定卡、道具 |
| `critical_text` | 标题、关键词、结论、数字 |
| `cover_title` | 第 0 帧话数标题卡 |
| `subtitles` | 可选内嵌字幕 |

### 4.2 关键位置

- 内容左边界 {{CONTENT_LEFT_PX}}px，内容宽度 {{CONTENT_WIDTH_PX}}px。
- 封面标题最大宽度 {{COVER_MAX_WIDTH_PX}}px，字幕最大宽度 {{SUBTITLE_MAX_WIDTH_PX}}px。
- {{AVOIDANCE_ZONES}}：标题、关键词、拟声字和结论都不得进入。
- 云和集中线可以铺满画面，但它们只是背景层，不承载任何信息。

## 5. 色彩系统

| Token | 色值 | 用途 |
|---|---|---|
| canvas | `#8FD3FF` | 晴空，画面最底层 |
| sky_deep | `#2A6FC4` | 高空、天空渐变上端、强调色块 |
| cloud | `#FFFFFF` | 积云、描边字填充、深色面板上的文字 |
| cloud_shade | `#C9D6F2` | 云和面板的赛璐珞硬阴影、分格底纹 |
| paper | `#FFF8EC` | 文字面板、分格底、设定纸 |
| ink | `#1B2240` | 墨线描边、正文、描边字外描边 |
| ink_soft | `#4A5578` | 浅色面板上的次级说明、编号 |
| sakura | `#FF7FA8` | 樱色贴纸、话数胶囊、温柔的强调 |
| sunbeam | `#FFD23F` | 关键词荧光笔、星芒、燃点贴纸 |
| impact_red | `#C42B3A` | 错误、危险、“×”印章、拟声字底 |
| hope_green | `#2FB574` | 正确、完成、“○”印章、好结局 |

### 5.1 对比度

| 文字 | 底色 | 对比度 |
|---|---|---:|
| ink | paper | ≈ 14.7 |
| ink | canvas | ≈ 9.6 |
| ink | sunbeam | ≈ 10.8 |
| ink | cloud_shade | ≈ 10.7 |
| ink | sakura | ≈ 6.6 |
| ink | hope_green | ≈ 5.9 |
| ink_soft | paper | ≈ 7.0 |
| impact_red | paper | ≈ 5.3 |
| cloud | ink | ≈ 15.6 |
| cloud | impact_red | ≈ 5.6 |
| cloud | sky_deep | ≈ 5.0 |

`cloud` 文字放在 `canvas` 晴空上对比度不足 2:1，所以天空上**只允许描边字**：`cloud` 填充 + 至少 8px `ink` 外描边，可读性来自描边。

### 5.2 用色分寸

- 晴空 + 云占画面大部分面积，文字面板是第二大面积。
- `sunbeam` 一屏只标一个关键词；`sakura` 用于话数胶囊和小贴纸；`impact_red` 与 `hope_green` 只在需要表达对错时出现。
- 不为“热闹”同时铺满所有强调色：一个镜头的主强调色只有一个，其他强调色只做小面积点缀。

## 6. 字体与信息层级

### 6.1 字体角色

- 封面、镜头标题、拟声字：`Smiley Sans`（得意黑）400。字体自带斜体，不再叠加斜体或倾斜变换。
- 话数、编号、英文小标、`EPISODE` / `NEXT EPISODE`：`Bebas Neue` 400。它没有中文字形，中文会回退到 Noto Sans SC，所以中文小标直接写进 `primary_stack`。
- 正文、说明、标签、字幕：`Noto Sans SC` 400 / 700。
- 三种字体都必须显式嵌入，不依赖渲染机的系统字体。

### 6.2 字号

| 角色 | 字号 | 字重 |
|---|---:|---:|
| 封面标题 | 92–132px | 400（得意黑） |
| 镜头标题 / 拟声字 | 54–76px | 400（得意黑） |
| 正文 / 结论 | 26–36px | 400 / 700 |
| 标签 / 编号 / 元数据 | 22–28px | 700 |

标题行距 1.00–1.10，正文行距约 1.42。任何中文正文不小于 24px。

### 6.3 描边字

- 填充 `cloud`，外描边 `ink` 8–14px（按字号的约 10%），`paint-order: stroke fill`，`stroke-linejoin: round`。
- 可在描边外再加一层 `sky_deep` 硬投影，向右下偏移 6–10px，不模糊。
- 只用于 54px 以上的展示字；正文永远不用描边字。

## 7. 空间与圆角

### 7.1 留白

- 同组元素：12–20px。
- 堆叠卡片或分格：至少 16px。
- 不同信息组：32–60px。
- 主面板内边距：28–40px。
- 次级卡内边距：22–28px。
- 标签、编号、图标距边缘：至少 22px。
- 列表、设定页最后一行到底边：至少 22px。

### 7.2 圆角

- 6px：小标签、编号角标。
- 12px：贴纸、字幕底、按钮。
- 20px：文字面板、设定卡。
- 28px：大面板、对话气泡。
- 999px：话数胶囊、印章圆。
- 漫画分格是直角或斜切角，不加圆角——格子要像格子。

## 8. 组件语言

### 话数胶囊

`sakura` 胶囊，`ink` 2–3px 描边，内写 `Bebas Neue` 的 `EPISODE 01` 或中文“第 1 话”。放在标题上方左对齐。

### 文字面板

`paper` 底、20px 圆角、`ink` 5px 描边，右下方有一块同形 `ink` 硬阴影（偏移 8–12px，不模糊）。这是承载正文的默认容器。

### 漫画分格

`paper` 或 `cloud` 底，`ink` 5–6px 直角框。格间距 16–24px。斜切分格的倾角统一在 6°–12°。格内左上角可放 `Bebas Neue` 小编号。

### 集中线

以主焦点为圆心的放射状细三角，`ink` 低透明度（0.10–0.25）或 `cloud` 高透明度。内圈留空不小于主焦点外接圆；线条分布由固定种子预先算好。

### 拟声字

`Smiley Sans` 描边字，可整体旋转 −8° 到 8°；底下可垫一块 `impact_red` 或 `sunbeam` 的爆炸形贴纸。拟声字只是情绪标点，不得承载必须读懂的信息。全片最多三处。

### 印章

圆形“○”（`hope_green`）与“×”（`impact_red`），`ink` 描边，用于分格对照里标注对错。

### 设定卡

`paper` 底、`ink` 描边，上方一行 `Bebas Neue` 英文小标 + 中文名，下方一句说明和一条 `sunbeam` 能力条或刻度。卡角可有一张斜贴的 `cloud_shade` 胶带。

### 星芒与云

四角星芒用 `sunbeam` 或 `cloud`；积云是平涂 `cloud` + 底部 `cloud_shade` 硬阴影，轮廓由几个圆弧组成。

## 9. 四类镜头骨架

### 9.1 话数标题卡（proposition）

用于封面、钩子、章节开场和强结论。晴空与积云 + 话数胶囊 + 描边字大标题 + 一行副标题面板，标题背后可有一圈集中线。第 0 帧就是它的完成态。

![话数标题卡示例](../assets/style-guide/examples/proposition.png)

### 9.2 分格对照（comparison）

用于两种做法、误区与真相、之前与之后。画面被一条斜切格线分成两格，各自一个标题、一个道具和一句结论；被否定的一方盖 `impact_red` “×”印章，被肯定的一方盖 `hope_green` “○”印章。

![分格对照示例](../assets/style-guide/examples/comparison.png)

### 9.3 分镜推进（process）

用于步骤、因果链和成长阶段。三到四个分格按阅读方向排列，每格一个编号、一个道具和一句短句；当前步骤的格子用 `sunbeam` 角标或集中线点亮，已完成的格子降为 `cloud_shade` 底。

![分镜推进示例](../assets/style-guide/examples/process.png)

### 9.4 设定资料（capability_deck）

用于多维要点、能力与特征、全片总结。一页 `paper` 设定纸，上方是主题名，下方 2×2 设定卡网格，每张卡是一条要点；可以有一张卡用 `sunbeam` 描边标为“核心设定”。

![设定资料示例](../assets/style-guide/examples/capability_deck.png)

## 10. 动画语法

### 10.1 三阶段

- **Build 28%**：背景就位后，话数 → 标题 → 面板依次砸入，或分格逐格 PANEL IN。
- **Breathe 52%**：画面停住，只保留一种环境动作，给观众读完。
- **Resolve 20%**：印章落定、关键词被荧光笔扫亮，或 EYECATCH 转场切走。

### 10.2 品牌动作词

`TITLE DROP`、`ZOOM LINES`、`PANEL IN`、`SMEAR`、`POP`、`SPARKLE`、`EYECATCH`。

| 动作词 | 做法 |
|---|---|
| TITLE DROP | 标题从上方 40–80px 处砸下，轻微过冲后硬停，可带 0.15s 小幅震屏 |
| ZOOM LINES | 集中线从外向内收拢 0.20–0.30s，停在主焦点外接圆外 |
| PANEL IN | 分格按阅读顺序滑入或从格线处展开，相邻格间隔 0.10–0.20s |
| SMEAR | 快速移动的图形在 2–3 帧内带一道同色拖影 |
| POP | 贴纸、印章从 0.6 倍放大到 1 倍，`back.out(1.4)` |
| SPARKLE | 四角星芒在关键词旁闪一次（放大 + 旋转 45°），不循环 |
| EYECATCH | 转场：一块 `sky_deep` 或 `sakura` 色块斜扫全屏 0.30–0.40s，中间停 4–6 帧再扫开 |

入场 0.20–0.45s，退场 0.15–0.30s。入场用 `expo.out` / `power3.out` / `back.out(1.4)`，退场用 `power2.in` / `expo.in`。第一动作延迟 0.10–0.25s。一个镜头中相同 ease 的独立 tween 不超过两个。

### 10.3 番剧手感

- 关键姿势 + 停顿：动作快进快停，停住后完全静止。
- 一拍二：图形道具可以按 `Math.floor(frame / 2) * 2` 取样，每两帧更新一次；文字入场保持逐帧顺滑。
- 拖影只给图形，持续不超过 3 帧。

### 10.4 环境动作（三选一，最多一种）

- 云整镜横移不超过 40px。
- 集中线每 6 帧在两套预计算的线组之间轮换（不随机）。
- 星芒在固定位置轻微明暗闪烁。

### 10.5 转场

- 同一段内：分格切换、面板替换，背景天空不动。
- 换章节：EYECATCH 色块斜扫，或白云横向推过画面。
- 禁止全屏闪白、频闪、持续震屏和弹簧/橡皮筋效果。

## 11. 字幕、口播与声音

### 字幕

- 可选，最多两行，32–38px，最大宽度 {{SUBTITLE_MAX_WIDTH_PX}}px，行距 1.30–1.40。
- 推荐 `rgba(27,34,64,0.86)` 底、`cloud` 文字、14×22px 内边距、12px 圆角。
- 字幕只在 `safe_area.subtitles` 内，不与面板或分格重叠。

### 口播

- 保持人声原速；可以有更有活力的语气，但不使用变声或加速。
- 燃点处给画面留出停顿，不用拉伸人声填时长。

### BGM 与 SFX

- BGM 用明快的番剧风格编曲：吉他、弦乐、钢琴、轻快鼓组；燃点段落可以更强，但有人声时必须下压。
- SFX 只用于标题砸入、集中线、分格切换、印章和结论，同时最多两个；拟声字不必每个都配音效。
- 响度目标见 frontmatter `audio`：人声 -18 至 -16 LUFS，BGM -30 至 -26 LUFS 并在有人声时下压 6–10dB，成片 -16 LUFS ±1、真峰值不高于 -1 dBTP。

## 12. 首帧封面

- 第 0 帧是话数标题卡的完整完成态：天空、云、话数胶囊、标题全部就位。
- 默认两行，最多三行；单行不超过 8 个全角字符；字号 92–132px。
- 标题是描边字时，对比度按 `cloud` 填充对 `ink` 描边计算，必须不低于 7:1（实际约 15.6）；描边宽度不得小于 8px。
- 30fps 下至少稳定 18 帧后才允许转场。
- 不得以黑帧、空白、标题下落中或集中线收拢中的中间态开场。

## 13. 不可变项与可变项

### 不可变

- 画布、核心色、字体角色、安全区、间距和圆角。
- 文字只落在面板上或使用描边字。
- 四类骨架的语义用途。
- 动作词、三阶段节奏、关键姿势 + 停顿的手感。
- 字幕、封面、禁用项和验收门槛。

### 可变

- 天空时段（清晨、正午、傍晚的晴空，都在 token 色内表现）。
- 道具主题（书包、纸飞机、便当、自行车、电车、天台栏杆……）。
- 分格数量（2–4 格）、设定卡数量（3–4 张）。
- 拟声字的内容与位置（全片最多三处）。

## 14. Do / Don’t

### Do

- 用话数标题卡开场，像番剧每集的标题。
- 一格只讲一件事，按阅读顺序推进。
- 用集中线把视线收向唯一的关键词。
- 让动作快进快停，停住后给观众读完。
- 用剪影、手势和道具暗示人物与情绪。

### Don’t

- 不画、不描、不仿任何动画作品的角色、人脸、Logo、标题字形和片头构图。
- 不使用照片或 AI 生成的动漫背景、立绘。
- 不把正文直接压在天空上，不让集中线穿过文字。
- 不在 `sakura` / `hope_green` / `sunbeam` 上放 `ink` 以外的文字。
- 不用渐变文字、柔和渐变表现体积。
- 不用全屏闪白、频闪、持续震屏和橡皮筋弹跳。

## 15. 制作与验收清单

### 制作前

- [ ] 明确本镜头属于哪种骨架。
- [ ] 写出这一拍必须被读到的那个词，以及集中线指向哪里。
- [ ] 标出主焦点的登场顺序（整镜最多两个）和背景/中景/前景三个层次。
- [ ] 按 `safe_area` 像素算好面板与分格的边界。

### 画面

- [ ] 色值全部来自 token。
- [ ] 字号、间距、圆角符合范围，中文正文不小于 24px。
- [ ] `typography.font_files` 用到的每个字重都有 `@font-face`，`src` 指向镜头目录内真实存在的文件，且都是 `font-display: block`。渲染机不装系统字体，漏一条会静默回退成通用字体，本地看不出来。
- [ ] 文字只在面板上，或是至少 8px `ink` 描边的描边字。
- [ ] 集中线不穿过文字；标签和编号距边缘至少 22px，设定页底部至少 22px。
- [ ] 画面中没有任何动画作品的角色、人脸、Logo 或标题字形。

### 动画

- [ ] Build / Breathe / Resolve 完整。
- [ ] 动作快进快停，文字停住后保持静止直到读完。
- [ ] 每镜头最多一种环境动作；集中线分布由固定种子预计算。
- [ ] 动画确定性、可寻址、任意帧可重建。

### 声音与交付

- [ ] 人声清晰且保持原速。
- [ ] BGM ducking 和淡入淡出正确。
- [ ] SFX 同时不超过两个，拟声字不逐个配音效。
- [ ] 第 0 帧完成并稳定至少 18 帧。
- [ ] {{CANVAS}}、30fps、H.264/yuv420p/BT.709。
