

# “自定义”视频风格说明书（草稿）

- 状态：草稿，等待按 `docs/style-brief.md` 定稿
- 基准画幅：{{CANVAS}}，30fps，{{ORIENTATION}}

本说明书目前只是占位。frontmatter 里的数值沿用了默认风格的结构性取值，只为让文件字段齐全，**不代表用户要的风格**。定稿时按 `frame.md` 正文「定稿要做的事」逐项改写，并保持本文件 frontmatter 与 `frame.md` 完全一致。

定稿后的说明书至少包含：

1. 风格定位：一句话人格与三到五个关键词，适用与不适用的题材。
2. 配色：每个 `colors` token 的用途，哪些颜色只能用在哪类元素上。
3. 字体：每个字体栈的角色、字重与字号区间。
4. 构图：四种镜头骨架各自的版式要点，对照 `assets/style-guide/examples/` 下的示例图。
5. 动效：入场、退场、转场的动作词与缓动，以及禁用的动作。
6. 字幕与封面：沿用 frontmatter 的 `subtitles` 与 `cover` 约束。
7. 声音：BGM 与 SFX 的取向，响度目标沿用 frontmatter 的 `audio`。
8. 验收清单：渲染后逐项核对的条目。
